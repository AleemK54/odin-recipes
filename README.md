# Swat Valley Odin Recipes

This is my submission for the HTML Recipes project from [The Odin Project](https://www.theodinproject.com/). 

Instead of using generic recipes, I wanted to share the traditional and hearty cuisine of the **Swat Valley** (Khyber Pakhtunkhwa, Pakistan). This region's food is heavily influenced by Central Asian and Afghan flavors, focusing on high-quality meat, rice, and simple, powerful spices.

## The Dishes

Here are the recipes featured in this project:
*   **Kabuli Pulao:** A fragrant, celebratory rice dish cooked with lamb, caramelized carrots, and sweet raisins.
*   **Rosh:** The ultimate Pashtun comfort food—meat slow-cooked to perfection in its own fat with tomatoes and green chilies.
*   **Chapli Kabab:** Iconic flat kebabs made with minced meat, crushed coriander, pomegranate seeds, and tomatoes.
*   **Kehwa:** The essential Pashtun green tea, brewed with cardamom and served hot.

## Technologies Used
*   HTML5 (Semantic tags, lists, images, and relative links)

## How to Use
Simply open the `index.html` file in your web browser, or use the VS Code "Live Server" extension. You can navigate between the homepage and the individual recipe pages using the relative links.
